## Цель

Настроить Doxygen для Python-кода проекта, создать конфигурацию, интегрировать генерацию документации в Makefile, добавить комментарии к public API runtime-модулей и обеспечить воспроизводимый конвейер генерации HTML/XML артефактов.

## Границы

### Входит

- Создание и настройка `Doxyfile` в корне репозитория для Python-кода.
- Генерация HTML и XML вывода в `output/doxygen/`.
- Добавление `output/doxygen/` в `.gitignore`.
- Добавление целей `docs` и `docs-check` в `Makefile`.
- Документирование public API runtime-модулей в `scripts/` (phase 1: `@brief`, `@param`, `@return`, `@raises`).
- Документирование key internal функций (phase 2: `@note`, `@todo`, `@pre`, `@post`, `@see`).
- Проверка отсутствия warnings при генерации Doxygen.
- Обновление `AGENTS.md`, если managed-блоки ссылаются на инструменты документирования.

### Не входит

- Документирование `tests/` (отложено на отдельную задачу).
- Документирование Markdown-артефактов (`references/`, `assets/`).
- Переход на Sphinx, MkDocs или другой документирующий инструмент.
- Изменение логики runtime-модулей.
- Добавление новых runtime/package зависимостей.

- `.gitignore` исключает `output/doxygen/`.
